## Description

As a shopper I can filter the product listing by category and price
range. Results update without a full page reload.

## Acceptance Criteria

1. Category filter shows only products in the selected category.
2. Price range filter shows only products within the min/max entered.
3. Both filters can be combined.
4. Applying a filter does not reload the page; the URL reflects the active filters.
5. Clearing filters restores the full listing.
